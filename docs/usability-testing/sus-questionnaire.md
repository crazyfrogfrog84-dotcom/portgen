# System Usability Scale questionnaire

Ask the participant to rate each statement based on the PortGen session just completed. Use a five-point scale: **1 Strongly disagree**, **2 Disagree**, **3 Neither agree nor disagree**, **4 Agree**, **5 Strongly agree**. Record one response per statement. Do not calculate a project score until real responses have been collected.

| No. | Statement | Response 1-5 |
|---:|---|---|
| 1 | I think that I would like to use this system frequently. | To be completed with classmates |
| 2 | I found the system unnecessarily complex. | To be completed with classmates |
| 3 | I thought the system was easy to use. | To be completed with classmates |
| 4 | I think that I would need the support of a technical person to be able to use this system. | To be completed with classmates |
| 5 | I found the various functions in this system were well integrated. | To be completed with classmates |
| 6 | I thought there was too much inconsistency in this system. | To be completed with classmates |
| 7 | I would imagine that most people would learn to use this system very quickly. | To be completed with classmates |
| 8 | I found the system very cumbersome to use. | To be completed with classmates |
| 9 | I felt very confident using the system. | To be completed with classmates |
| 10 | I needed to learn a lot of things before I could get going with this system. | To be completed with classmates |

## Scoring note

For each odd-numbered item, subtract 1 from the response. For each even-numbered item, subtract the response from 5. Add the ten adjusted values and multiply by 2.5 to obtain a SUS score from 0 to 100. The score is a standardized usability scale, not a percentage of tasks completed. Record the number of participants and each raw response set before summarizing results.
