# PortGen usability test script

## Purpose

Observe whether a first-time student, freelancer, or job seeker can create, publish, manage, and revise a portfolio. This is a moderated study kit. The steps below do not contain participant results.

## Before the session

- Invite a classmate who has not built a PortGen portfolio before.
- Use a local or designated test environment with fictional information only.
- Ask the participant to think aloud while working. Do not teach the interface during a task.
- Record consent and any accessibility accommodations using the course process.
- Do not collect passwords, private contact information, or real portfolio details.
- Tell the participant they are evaluating the interface, not being evaluated.

## Opening script

“Thank you for helping. I’m evaluating PortGen, a portfolio builder for students, freelancers, and job seekers. I’ll ask you to complete five tasks. Please describe what you are looking for and what you expect to happen. I may take notes about the interface, but there are no right or wrong answers. You can stop at any time.”

## Tasks

| Task | Participant prompt | Completion evidence |
|---:|---|---|
| 1 | Create a portfolio using the fictional profile card provided by the moderator, then choose a template and find the public share link. | The participant reaches the completion screen and identifies the public link without moderator help. |
| 2 | Compare the available template styles and change the portfolio to the one you prefer. | The participant chooses another template and sees it on the public portfolio. |
| 3 | Open the private management link, edit the headline, and save the change. | The participant edits through the private link and confirms the changed public content. |
| 4 | Start deleting the portfolio, then undo the deletion. | The participant recognizes the confirmation dialog, uses Undo within the time window, and returns to management. |
| 5 | Find the keyboard shortcuts and use a shortcut to move between creation steps or save a draft. | The participant locates the help and demonstrates a listed shortcut. |

## Moderator prompts

Use only when the participant stops speaking for a while. Avoid suggesting controls or answers.

- “What are you thinking now?”
- “What did you expect to happen?”
- “What would you try next?”
- “How confident are you that this is complete?”

## Close

Ask: “Which part felt clearest? Which part required the most effort? What would you change first?” Then offer the SUS questionnaire in `docs/usability-testing/sus-questionnaire.md`. Do not explain a feature until the tasks and questionnaire are complete.

## Participant record

Complete one observation sheet for each participant. Use a participant code rather than a name. Leave identity and consent records in the course's approved location, not in this repository.
