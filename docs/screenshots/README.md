# Browser evidence

Playwright generates this gallery with `npm run test:e2e`. Each screen has mobile (375 × 812) and desktop (1280 × 800) captures. The suite also checks each mobile screen at 320 CSS pixels, audits the page with axe-core at both documented viewport sizes, and verifies visible controls meet the 44 × 44 CSS-pixel floor.

The gallery covers the three creation steps, template previews and rendered templates, the management and edit screens, the delete/undo screen, help and shortcut dialog, friendly error pages, and a dark-mode template. Portfolio details in the images are fictional test data. The signed owner-management URL is redacted in saved screenshots.
